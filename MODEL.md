# MODEL — obsmage, for a brand-new reader

**Direction (Corwin, 2026-11-01).** obsmage is OBS Studio kept as a living, literate configuration,
grown toward a desktop you can work with your hands in front of two cameras. It is the lab's
principal focus, and the place where the lab means to show the best UI/UX it can now make: things
that look right, and that tell the story of how we learned to make them.

**The load-bearing ideas**
1. *The whole configuration is ours to hold.* Atoms in, atoms out, losslessly, so a person, a tool
   and an agent all see the same picture.
2. *Narrow tools are cheap.* Because the atom layer joins and splits, a feature reads only its atoms.
3. *The instrument raises; the person decides.* Patterns (co-changing atoms, a mis-bound monitor) are
   reported, never acted on, until the interface can show the phase transition and the person's
   permission to cross it.
4. *Upstream first.* Use what OBS already does well; patch only when needed, carry patches per
   upstream version, offer them back when ready.
5. *No telemetry in this phase.* Feedback comes from people, by their choice.
